# Sample Project

A tiny fixture directory used only by the `file_explorer` and `readme_agent`
demo scripts (`python -m game.examples.file_explorer` /
`python -m game.examples.readme_agent`), so those demos are self-contained
and produce the same output no matter where they're run from. It has
nothing to do with the game framework itself — see the top-level README.md
for that.
